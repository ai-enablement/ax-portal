# RPA 원본 기능 대조 (2026-09-28)

최신 사용자 지시: 요청자 탭 3종 유지. 일반 사용자는 직접 작성자/부서가 아닌 명시적 PIC 이메일 연결로 범위를 제한한다. Admin, team_leader, team_member는 전체 조회 및 동일 관리 기능을 사용한다.

| 원본 기능 | 구현 / 검증 |
|---|---|
| 진행 현황 칸반 | 유지, 반려/보류 표시 추가 |
| 요청자: 내 요청 과제 목록 / 관리자: 과제 둘러보기 | 복원, 같은 서버 PIC scope 사용 |
| 마스터 14열 | 복원, 원본 엑셀 필드 참조; 날짜/요일 없는 값은 미등록 |
| 상세필터: 상태, 우선순위, 과제 | 복원, 과제번호 중복에 대비해 내부 ID로 필터 |
| 행별 오류/수정 요청 | 대상 과제 선택 상태로 폼 열기 |
| 행별 이력로그 | 과제별 요청 이력 집계, 유형 필터, 상세 요청 이동 |
| 등록 요청 건수 / 진행 건수 | 해당 과제 요청으로 이동; 실제 데이터 기준 |
| 관리자 담당자 배정, 원인/조치/예정일 입력 | 저장 API 추가, 서버 역할 검사 |
| 단계 변경 / 현재 단계 완료 | 저장 API 추가, 완료 시각·작업자·전후 값 기록 |
| 동시 수정 | 수정 시각 기반 충돌 검증 |
| 신규 마스터 등록 / 요일 설정 | 폼 및 API 추가, 중복 코드 거절 |
| 요청자 상세 읽기 전용 | 관리 폼 숨김 + API 거절 |
| 완료 알림 메일 | 미완료: 실제 전송 연동 없음, 발송 성공을 가장하지 않음 |
| 샘플 데이터 초기화 | 운영 데이터 보호를 위해 의도적으로 제외 |

## 검증

- 단위 테스트 5개 통과.
- TEMP 테이블 통합 테스트 31개 통과 (영구 데이터 변경 없음).
- ESLint 및 TypeScript 통과.
- 브라우저: 마스터 517개, 원본 14열, 이력로그 팝업, 프로젝트 ID 필터 이동 확인.
- 실제 요청 생성·단계 변경 브라우저 검증은 사용자 테스트 기록 생성 승인 대기.
- 스크린샷 오른쪽 영역 캡처 잘림 때문에 선택 시안과 완전한 시각 비교는 미완료.

운영 배포하지 않음. 전체 원본 기능 동등성 완료로 간주하지 말 것.
