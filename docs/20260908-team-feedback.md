## DB 적용 선행 조건

초기 DB 연결 오류는 해결되었으며, 사용자가 아래 마이그레이션을 적용한 후 문서 유형·단계·플랫폼의 네 제약 조건을 실제 DB에서 재확인했다. 배포 시 재실행할 필요는 없다.

다른 환경에 동일 버전을 설치할 때에는 스키마 소유 권한이 있는 환경으로 실행:

```powershell
node --env-file=.env server/migrate-intake-feedback.mjs
```

마이그레이션은 허용 문서 유형·단계·플랫폼 값만 확장한다. 기존 문서, 프로젝트, 승인 기록, Gallery 신청 데이터는 삭제·변환하지 않는다. 새 스키마 적용 후 앱을 배포해야 한다. 역버전 앱도 기존 데이터 값은 계속 읽을 수 있다.

`scripts/feedback-ui-fixture.mjs`는 127.0.0.1:4196의 격리된 메모리 테스트 서버다. 4194의 빌드된 앱 정적 화면에만 프록시하며 `/api`는 임시 데이터로 응답한다. DB·Azure AI·메일을 호출하지 않는다. 실제 운영 검증을 대신하지 않으며 운영 배포 대상이 아니다.

실제 PostgreSQL 임시 테이블·롤백 검증과 ARD-Lite 원문·버전 및 플랫폼 제약 검증을 통과했다. 운영 데이터는 이 검증에서 변경하지 않았다. MS 계정 역할별 UI 클릭은 브라우저 연결 문제로 완료하지 못했다. 배포 파이프라인은 기존 실제 Azure INT/FEA preflight를 실행하며, 이관 후 FEA는 동일 모델 호출 경로에 대해 모의 응답으로 검증했다.
