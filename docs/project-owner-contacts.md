# Project Owner 연락처

- 신규 과제 등록: Owner MS 계정 이메일 필수. ‘요구자와 동일’이면 요구자 이메일을 사용한다. 일반 User의 요구자 이메일은 서버 인증 계정에서 가져온다.
- 다른 Owner: 이름·소속과 이메일을 별도로 입력한다. 이메일 기준으로 기존 계정을 연결하거나 일반 User 계정을 생성한다. 계정 이름·역할·활성 상태를 변경하지 않는다. 비활성/다른 조직 계정은 거절한다.
- 과거 이관: 미확보 연락처는 빈 값으로 저장 가능. 메일 없는 오너를 등록자 계정으로 추정하지 않는다.
- `intake_requests.raw_answers.portalState.projectOwnerEmail` / `requesterEmail`에 등록 시 연락처를 저장하고, `projects.owner_id` 및 `project_members`의 owner 관계를 `users.email` 계정과 연결한다. 신규 테이블/마이그레이션은 없다.
- 기존 이름-only 등록 건은 과거에 등록자 계정으로 잘못 연결되었을 가능성이 있으므로 이메일을 자동 역산하거나 일괄 보정하지 않는다. 별도 확인/보완이 필요하다.
- 연락처는 일반 문서 PATCH로 변경할 수 없다. 등록 후 계정 이메일 변경은 기존 Admin & Governance 계정 관리에서 처리한다. 오너 교체/기존 프로젝트 연락처 보완 화면은 이번 범위에 포함하지 않는다.
- 실제 메일/Teams 전송, 자동 알림 일정, 승인 권한 변경은 구현하지 않는다. 후속 작업에서 단계별 대상자·중복 방지·재시도·발송 이력과 전송 서비스 권한을 구현해야 한다.
